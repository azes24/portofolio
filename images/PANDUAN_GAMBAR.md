## 💡 Tips Praktis:
- **Format file yang disarankan**: `.webp` (ukuran kecil dan kualitas sangat jernih), atau bisa juga `.jpg` / `.png`.
- Jika Anda mengganti file dengan ekstensi lain (contoh: dari `ilsah-madura.webp` menjadi `ilsah-madura.png`), jangan lupa sesuaikan nama ekstensinya di file HTML terkait (`index.html` dan `profile.html`).
